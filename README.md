# srmjava

Java programs and practice work from my coursework at SRM Institute of Science and Technology, including BridgeLabz assignments.

## About

This repository collects the Java programs I write while learning. Each program is kept small and focused on one concept so it is easy to revisit.

## Topics Covered

- Java basics: variables, data types, and operators
- Control flow: conditionals and loops
- Methods and arrays
- Strings and string handling
- Object-oriented programming: classes, objects, inheritance, and polymorphism

## Getting Started

Requirements: JDK 8 or newer.

git clone https://github.com/Vicky-45-11/srmjava.git
cd srmjava

Compile and run any program:

javac FileName.java
java FileName

## Notes

- Each file can be compiled and run on its own.
- More programs will be added as the course goes on.
